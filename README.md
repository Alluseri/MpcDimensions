# MpcUtils
A set of handy utilities for Mapartcraft.

## How to install
1. Install TamperMonkey (surely you already have it): [Chrome](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo), [Firefox](https://addons.mozilla.org/en-US/firefox/addon/tampermonkey/)
2. On Chromium-based browsers, make sure to give TamperMonkey permission to load user scripts (or enable Developer Mode)
3. Open [this link](https://github.com/Alluseri/MpcUtils/raw/refs/heads/main/MpcUtils.user.js)
4. Click "Install" (or "Reinstall", or "Update")
5. Happy usage!
